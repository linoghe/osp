Three-track program: The Schema Track and Markdown Site Track run in parallel with shared PM governance. OSP delivers strategy, content, and specifications; the technical implementation is optionally subcontracted.
4.02 Calendar Duration

~6 Calendar Weeks (Jun 1 – Jul 9, 2026)

  • Schema Track completes in ~4 weeks — the core strategy, architecture, and content specification work wraps by end of June.
  • Markdown Site Track extends ~2 weeks beyond due to the technical partner's pipeline build (CMS queries, templating, build/deploy) and a final validation pass.
  • Effort is front-loaded: weeks 1-3 carry the heaviest consultancy days, with technical implementation and validation filling weeks 4-6.
Distribution: The ~36 days of effort are concentrated early. OSP strategy and content work peaks in weeks 1-3, the tech partner build runs weeks 3-5, and validation closes weeks 5-6.
4.03 Role Mix & Seniority

Four-Role Team, OSP-Led

  • OSP Sr. Consultant: strategy, information architecture, schema specifications, and validation across both tracks.
  • OSP Content: bilingual content values (DE + EN), page-level specifications, and documentation.
  • Technical (optional subcontract): pipeline implementation — CMS queries, templating, build/deploy. Scoped to the Markdown Site Track only.
  • PM: 15% rider covering kickoff, weekly status meetings, risk tracking, and cross-track coordination.
Dynamic pricing model: OSP handles everything except the optional technical implementation. The engagement can be priced with or without the tech subcontract, letting the client use an existing partner if preferred.
