05 Pricing Context

Context Relevant to Pricing

Exclusions, commercial terms, and differentiating factors that may shift the number.

5.01 Exclusions

What's NOT in Scope

Technical implementation — the render pipeline (CMS queries, markdown templating, build/deploy) — is optionally subcontracted by OSP or handled by the client's existing technical partner.

  • CMS queries & data layer — wiring content models to templates
  • Markdown templating & build pipeline — static-site generation, CI/CD
  • Hosting & deployment — server configuration, performance tuning
  • Ongoing site maintenance after handover
The pricing model includes technical implementation costs, but those line items can be zeroed out if OSP does not subcontract the work (i.e., the client's own technical partner handles it). The total adjusts automatically.

5.03 Differentiating Factors

Why This May Price Higher

  • The schema/GEO and AI-search-readiness combination, executed bilingually, is a niche specialization.
  • Competitive audit of 7 peer properties (in the same hotel collection, plus the collection's own brand site) found that none currently emit the entity-graph schema relationship the spec will create.
  • The validation phase produces evidence (specifically, a pre/post AI-engine query comparison segmented by language) that the client can use internally and with the parent brand collection.
The deliverable is a measurable competitive differentiator for the client, not a parity move. No peer property in the collection currently has this capability.
